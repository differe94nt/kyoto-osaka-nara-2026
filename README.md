# 2026 京阪奈 6 天 5 夜 · 互動行程表

四人同行，2026/09/24 – 09/29。手機開啟即可使用，分成三個分頁：

| 分頁 | 內容 |
|---|---|
| 🗓️ **行程** | 六天行程，**每天都有「☀️ 晴天／🌧️ 雨天」兩套方案**，一鍵切換；可替換／加選景點 |
| 📋 **資訊** | 出發前 Checklist、航班、住宿、交通速查、緊急聯絡（點了直接撥號） |
| 💴 **分帳** | 日幣匯率換算 ＋ 誰先墊了什麼錢、除以幾個人、自動算出誰該還誰多少 |

## 怎麼開

直接用瀏覽器打開 `index.html` 就好（不需要架伺服器、離線也能用）。
放到 GitHub Pages 後，手機加入主畫面就像一個 App。

## 檔案結構

```
index.html            頁面骨架（很少需要動）
assets/style.css      樣式；配色集中在最上面的 :root
assets/app.js         互動邏輯（分頁、天氣切換、加選、Checklist、匯率、分帳）
data/itinerary.js  ★  所有行程內容都在這裡，平常只要改這一個檔
```

## 三種改行程的方式

### 1. 網頁上直接改（最快，改完存在自己的瀏覽器裡）

- **「🔁 可替換／加選行程」**：勾選就插進當天的時間軸，取消就拿掉。每個選項都寫了「取捨」，說明加了會犧牲什麼。
- **「＋ 在這天加一個自己的行程」**：每天卡片下方，填時間＋名稱就能新增，自訂項目右上角的 ✕ 可刪除。
- 勾選狀態、加選、自訂行程、天氣模式都會自動記在瀏覽器（localStorage）。按「↺ 全部重設」可回到預設。
- 注意：這些只存在自己的手機／電腦上，**不會同步給其他三個人**。要讓大家都看到，請改 `data/itinerary.js` 再推上去。

### 2. 改 `data/itinerary.js`（正式版，大家都看得到）

在對應那天的 `items` 陣列裡加一段：

```js
{ t: '15:30', tag: '購物', w: 'all', title: '寶可夢中心 京都',
  place: '京都経済センター SUINA室町',
  desc: '說明文字',
  tips: ['小提醒一', '小提醒二'] },
```

| 欄位 | 說明 |
|---|---|
| `t` | 排序與顯示用時間，一律 `'HH:MM'`（24 小時制） |
| `time` | 選填。想顯示成「早上」「傍晚」時才填，排序仍看 `t` |
| `tag` | `交通` `景點` `美食` `購物` `祈福` `住宿` `休息` `提醒` |
| `w` | `'all'` 晴雨都做／`'sun'` 只有晴天／`'rain'` 只有雨天 |
| `place` | 選填。填了會自動長出「📍 地圖」按鈕（Google Maps） |
| `desc` `tips` | 選填。說明文字與小提醒清單 |

### 3. 加一個備選景點到「可替換」清單

在 `data/itinerary.js` 最下面的 `extras` 加一段，`on: true` 代表預設就加入行程：

```js
{ id: '自訂唯一代號', day: 'day5', t: '16:45', on: true,
  tag: '購物', w: 'all',
  title: '標題', place: '地圖用地名', desc: '說明',
  why: '取捨：加了會犧牲什麼、為什麼建議加' },
```

## 分帳怎麼用

1. 先在「同行成員」把四個人的名字改掉，之後的紀錄都會跟著顯示。
2. 每次有人先墊錢就記一筆：填項目、金額、幣別（日圓或台幣都可以混著記）、誰先付的，再勾選**這筆要分給誰**。
   - 四個人平分 → 四個都勾（除以 4）
   - 只幫某一個人代買 → 只勾那個人（他全額還你）
   - 三個人去某個景點 → 只勾那三個（除以 3）
3. 下方「結算」會自動算出每人已墊多少、應分攤多少，並給出**最少轉帳次數**的還錢方式。
4. 「⧉ 複製明細文字」可以把整份明細與結算複製成純文字，直接貼到群組裡。

紀錄存在各自的瀏覽器（localStorage），**不會互相同步**——建議指定一個人負責記帳。

## 匯率換算

- 開啟分頁時會自動抓即時匯率（open.er-api.com，失敗時改用 jsDelivr 的 currency-api）。
- 沒有網路時沿用上次抓到的匯率；都沒有就用預設值，畫面上會標示來源與時間。
- 可勾「手動指定匯率」填入信用卡或換鈔的實際匯率，分帳的台幣換算會一起改用這個數字。
- 台幣記的帳會用當下匯率換成日圓再分攤，所以**匯率改了，結算金額也會跟著變**。

## 其他功能

- **📍 跳到今天**：旅程期間會自動把當天卡片標紅並可一鍵跳過去。
- **🖨️ 列印／存成 PDF**：已寫好列印樣式，三個分頁會一次全部印出，按鈕與表單自動隱藏。
- **🆘 緊急聯絡**：手機上點一下直接撥號。
- 深色模式會跟隨系統設定。
- 「↺ 重設勾選與加選」在資訊分頁最下方，**不會**刪掉代墊紀錄；清空代墊要用分帳分頁自己的按鈕。
